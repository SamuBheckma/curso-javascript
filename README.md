# Curso Básico de JavaScript

### Repositório de Estudos

Este repositório reúne todo o conteúdo que aprendi durante o curso básico de JavaScript ministrado pelo **Curso em Vídeo**. Ao longo das aulas, explorei os seguintes tópicos fundamentais:

- Fundamentos da linguagem
- Tipos de dados e variáveis
- Operadores
- Estruturas condicionais
- Laços de repetição
- Arrays (vetores)
- Funções
- DOM

> ⚠️ **Nota:** Alguns arquivos foram perdidos durante a migração de sistemas operacionais, o que causou a exclusão de parte dos exercícios. No entanto, toda a base teórica e prática essencial está registrada neste repositório.
