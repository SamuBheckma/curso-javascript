# Gabaritos

Leia depois de resolver os [exercícios](../exercicios/README.md).
As soluções 01–03 mostram funções pequenas. As soluções 04 e 05 reexportam
as funções comentadas de [`praticas/logica.js`](../praticas/logica.js), também
usadas pelas interfaces para manter as mesmas regras.

A solução 06 combina [`06.html`](06.html) e [`06.js`](06.js).
Use `http://127.0.0.1:8080/gabaritos/06.html` com o servidor local ativo.
As soluções são uma possibilidade; clareza e cumprimento do contrato contam
mais do que reproduzir exatamente o mesmo código.
