# 04 · Repetições

Implemente `contar(inicio, fim, passo)` em [`04.js`](04.js).

Retorne um array contando até o limite, sem ultrapassá-lo. O passo é sempre positivo; o sentido vem de início e fim. Aceite apenas inteiros seguros. Rejeite passo zero, negativo, dados inválidos ou sequências acima de 1.000 elementos com `RangeError`, antes de iniciar o laço.

## Casos de aceitação

```text
contar(1, 6, 2) → [1, 3, 5]
contar(5, 1, 2) → [5, 3, 1]
contar(3, 3, 1) → [3]
contar(0, 5, 0) → RangeError
contar(0, 1000, 1) → RangeError
```

Antes de consultar a solução, acrescente um caso válido e um inválido.
