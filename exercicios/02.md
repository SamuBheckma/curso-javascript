# 02 · Operadores

Implemente `aplicarDesconto(preco, percentual)` em [`02.js`](02.js).

Retorne o preço após desconto. Aceite preço finito não negativo e percentual entre 0 e 100. Qualquer entrada inválida deve lançar `RangeError`. Não converta strings implicitamente. Use comparação aproximada em testes com decimais.

## Casos de aceitação

```text
aplicarDesconto(80, 15) → 68
aplicarDesconto(80, 100) → 0
aplicarDesconto(0, 0) → 0
aplicarDesconto(80, 101) → RangeError
aplicarDesconto('80', 15) → RangeError
```

Antes de consultar a solução, acrescente um caso válido e um inválido.
