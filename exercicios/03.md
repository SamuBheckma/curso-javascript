# 03 · Condições

Implemente `saudacao(hora)` em [`03.js`](03.js).

Retorne `Bom dia` para 0–11, `Boa tarde` para 12–17 e `Boa noite` para 18–23. Aceite somente horas inteiras nesse intervalo; fora dele, lance `RangeError`. O horário é uma convenção didática.

## Casos de aceitação

```text
saudacao(0) → 'Bom dia'
saudacao(12) → 'Boa tarde'
saudacao(18) → 'Boa noite'
saudacao(23) → 'Boa noite'
saudacao(24) → RangeError
```

Antes de consultar a solução, acrescente um caso válido e um inválido.
