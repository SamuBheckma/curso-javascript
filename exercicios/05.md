# 05 · Arrays e funções

Implemente `analisar(valores)` em [`05.js`](05.js).

Receba uma lista não vazia de inteiros distintos de 1 a 100. Retorne `{ quantidade, menor, maior, soma, media }`, preservando a ordem do array recebido. Rejeite lista vazia, duplicatas e entradas inválidas com `RangeError`.

## Casos de aceitação

```text
analisar([10, 2, 30]) → { quantidade: 3, menor: 2, maior: 30, soma: 42, media: 14 }
analisar([1]) → { quantidade: 1, menor: 1, maior: 1, soma: 1, media: 1 }
analisar([]) → RangeError
analisar([2, 2]) → RangeError
```

Antes de consultar a solução, acrescente um caso válido e um inválido.
