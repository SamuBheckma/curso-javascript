# Exercícios

Leia o enunciado numerado e edite o `.js` de mesmo número. Cada tentativa tem
assinaturas prontas e lança um erro até você implementar a função. Não é um defeito.

Crie `exercicios/tentativa.js` para chamar sua solução, por exemplo:

```js
import { apresentar } from './01.js';
console.log(apresentar('  Ana  ', 3)); // Ana concluiu 3 aulas.
```

Execute `node exercicios/tentativa.js`. Use `console.assert` ou `node:assert/strict`
para conferir os casos do enunciado. O módulo 06 é uma prática no navegador.
Compare com o gabarito somente depois de tentar. Não há prazo: avance quando
conseguir explicar o resultado e o tratamento das entradas inválidas.
